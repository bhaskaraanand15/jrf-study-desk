STUDY DESK: UGC NET / JRF COMPUTER SCIENCE & APPLICATIONS

Static HTML/CSS/JavaScript website. No build command, backend, analytics, ads, remote fonts or embeds are included.

Scope: UGC NET Paper 1 (General Paper) and Paper 2 (Computer Science & Applications, subject code 087). The preparation target is JRF-level mastery. AP SET has been removed from this project.

To preview: open index.html in a modern browser.
To publish: upload the complete folder contents to the root of a GitHub repository, then enable GitHub Pages from main / root.

IMPORTANT: NOT READY FOR PUBLIC LAUNCH. Complete launch-checklist.html first. Supply the real operator name and contact details, register and connect a custom domain, verify HTTPS, review all policies with qualified Indian counsel, and test accessibility and all functions. Do not claim legal compliance solely because policy pages exist.

Progress and notes are stored in browser localStorage and are not synced between devices. Export backups before clearing browser data.

Official syllabus reference: https://www.ugcnetonline.in/syllabus-new.php . Check the latest official UGC/NTA publication before each examination cycle. The website's detailed study expansions are preparation aids and must not be mistaken for additional official syllabus wording.

No cookie banner is included because this version has no analytics or non-essential tracking cookies. Reassess before adding any third-party tools or embeds.

Exam target setup: on Study plan, select a June, December or custom cycle, target year, qualification goal and (optionally) an officially announced exam date. The date is never guessed. Target settings are saved locally and included in backup export.
Navigation: active page highlighting is determined from the current page URL, rather than hard-coded to Overview.
